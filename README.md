# Bienvenido a tu app de Expo 

Este es un proyecto de [Expo](https://expo.dev) creado con [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Primeros pasos

1. Instala las dependencias
```bash
npm install

```


2. Inicia la aplicación
```bash
npx expo start

```



En la salida de la terminal encontrarás opciones para abrir la aplicación en:

* Una [compilación de desarrollo (development build)](https://docs.expo.dev/develop/development-builds/introduction/)
* Un [emulador de Android](https://docs.expo.dev/workflow/android-studio-emulator/)
* Un [simulador de iOS](https://docs.expo.dev/workflow/ios-simulator/)
* [Expo Go](https://expo.dev/go), un entorno de pruebas limitado para probar el desarrollo de aplicaciones con Expo

Puedes empezar a desarrollar editando los archivos dentro del directorio **src/app**. Este proyecto utiliza [enrutamiento basado en archivos (file-based routing)](https://docs.expo.dev/router/introduction).

## Obtener un proyecto limpio

Cuando estés listo, ejecuta:

```bash
npm run reset-project

```

Este comando moverá el código inicial al directorio **example** y creará un directorio **src/app** en blanco donde podrás empezar a desarrollar.

### Otros pasos de configuración

* Para configurar ESLint para el análisis de código (linting), ejecuta `npx expo lint`, o sigue nuestra guía sobre ["Usar ESLint y Prettier"](https://docs.expo.dev/guides/using-eslint/).
* Si deseas configurar pruebas unitarias, sigue nuestra guía sobre ["Pruebas unitarias con Jest"](https://docs.expo.dev/develop/unit-testing/).
* Aprende más sobre la configuración de TypeScript en esta plantilla en nuestra guía sobre ["Usar TypeScript"](https://docs.expo.dev/guides/typescript/).
